Movie Aggregator (RateMix)

Eine Filmseite, die Bewertungen von TMDB, IMDb, Rotten Tomatoes, Metacritic und Trakt nebeneinanderstellt und jeden daraus einen eigenen Score mischen lässt: Quellen an- und abschalten, gewichten, und der Wert rechnet sich sofort im Browser neu. Die Seite wartet nie auf externe APIs — Bewertungen kommen aus der eigenen Datenbank, BullMQ-Worker holen fehlende Daten im Hintergrund nach und halten ein tägliches API-Kontingent ein. Die Score-Formel liegt in einem geteilten Paket, damit API und Browser exakt denselben Code ausführen.

A movie site that puts ratings from TMDB, IMDb, Rotten Tomatoes, Metacritic and Trakt side by side and lets each person mix them into a score of their own: switch sources on or off, weight them, and the score recomputes instantly in the browser. Pages never wait on rating APIs — ratings come from the app’s own database, while BullMQ workers fetch what’s missing in the background and stay within a daily API quota. The scoring formula lives in a shared package, so the API and the browser run exactly the same code.
